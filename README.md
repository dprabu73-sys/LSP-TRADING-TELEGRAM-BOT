# LSP Trading Telegram Bot – Interactive Learning Portal

A beginner-friendly, installable web app (PWA) that teaches the LSP Trading Telegram Bot:
a practice Telegram simulator, 2-step confirmation sandbox, profit-stairs slider, sample ledger,
a 5-question quiz with a "Certified Safe Bot Trader" badge, and the printable 13-page PDF guide.

Practice only: it never connects to a broker or places orders.
